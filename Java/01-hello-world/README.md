# Hello World em Java

Primeiro programa em Java: imprime **"Olá, mundo!"** na tela.

## Conceitos praticados
- Estrutura de uma classe Java
- Método `main`, o ponto de entrada do programa
- Saída com `System.out.println`

## Saída
```
Olá, mundo!
```

## Como compilar e executar
```
javac -encoding UTF-8 HelloWorld.java
java HelloWorld
```
O `-encoding UTF-8` é necessário no Java 17 ou anterior para os acentos funcionarem.
