# Maior Nota da Turma

Lê as notas de 5 alunos, encontra a maior e mostra a posição de todos que tiraram essa nota. Se houver empate, todos aparecem.

## Conceitos praticados
- Busca do maior valor em um vetor
- Segunda varredura para encontrar empates

## Exemplo
```
Digite as notas dos 5 alunos:
7 9 6 9 8

Maior nota: 9
Posicao do(s) aluno(s) com a maior nota:
Posicao: 1
Posicao: 3
```

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
