# Temperaturas Acima da Média

A partir das temperaturas de 7 dias, calcula a média e mostra quais dias ficaram acima dela e quantos foram.

## Conceitos praticados
- Vetor inicializado na declaração
- Cálculo de média
- Comparação de cada elemento com a média

## Saída
```
Posicao 1 - Temperatura: 26 graus
Posicao 2 - Temperatura: 37 graus
Posicao 3 - Temperatura: 43 graus
Posicao 6 - Temperatura: 27 graus
Media das temperaturas: 25.571428
Quantidade de dias acima da media: 4
posicoes dos dias acima da media: 1
posicoes dos dias acima da media: 2
posicoes dos dias acima da media: 3
posicoes dos dias acima da media: 6
```

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
