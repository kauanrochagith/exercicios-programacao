# Soma das Linhas para Vetor

*Exercício de prova.* Soma cada linha de uma matriz 3x3 e guarda o total de cada uma em uma posição de um vetor.

```
5 4 1   -> 10
3 2 1   -> 6
3 3 3   -> 9
```

## Conceitos praticados
- Laços `for` aninhados
- Vetor de acumuladores (`soma[3]`)
- Transferir resultados da matriz para um vetor

## Saída
```
10
6
9
```

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
