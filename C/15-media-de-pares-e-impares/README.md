# Média de Pares e Ímpares

Lê 6 números inteiros, conta quantos são pares e quantos são ímpares e calcula a média de cada grupo.

## Conceitos praticados
- Paridade com `%`
- Conversão de tipo (`(float)`) para divisão com casas decimais
- Proteção contra divisão por zero

## Exemplo
```
Digite 6 numeros inteiros:
2 4 6 1 3 8
Quantidade de valores pares: 4
Quantidade de valores impares: 2
Media dos valores pares: 5.00
Media dos valores impares: 2.00
```

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
