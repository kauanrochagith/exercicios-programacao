# Avaliação de Clientes

Lê as notas (de 0 a 10) de 10 clientes e classifica cada uma:

| Nota | Categoria |
|---|---|
| 0 a 4 | Ruim |
| 5 a 7 | Regular |
| 8 a 10 | Boa |

No final, mostra quantas avaliações há em cada categoria e a média geral.

## Conceitos praticados
- Faixas de valores com `&&` e `if / else if`
- Contadores por categoria
- Cálculo de média

## Exemplo
```
Digite as notas dos 10 clientes:
10 8 5 3 7 9 2 6 8 10
Quantidade de avaliacoes ruins: 2
Quantidade de avaliacoes regulares: 3
Quantidade de avaliacoes boas: 5
Media das avaliacoes: 6.80
```

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
