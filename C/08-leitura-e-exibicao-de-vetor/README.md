# Leitura e Exibição de Vetor

Lê 4 números inteiros, guarda em um vetor e mostra o valor de cada posição.

## Conceitos praticados
- Declaração de vetor (`int x[4]`)
- Laço `for` para preencher e para percorrer o vetor
- Índices começando em 0

## Exemplo
```
Digite um numero para a posicao 0: 10
Digite um numero para a posicao 1: 20
Digite um numero para a posicao 2: 30
Digite um numero para a posicao 3: 40

Valores do vetor:
posicao 0 = 10
posicao 1 = 20
posicao 2 = 30
posicao 3 = 40
```

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
