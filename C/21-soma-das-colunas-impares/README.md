# Soma das Colunas Ímpares

Soma os elementos de cada coluna de índice **ímpar** (1 e 3) de uma matriz 4x4 e guarda os resultados em um vetor.

## Conceitos praticados
- Percorrer a matriz coluna por coluna (laço externo nas colunas)
- Paridade do índice com `%`

## Saída
```
Vetor com as somas das colunas impares:
32 40
```
- Coluna 1: 2 + 6 + 10 + 14 = 32
- Coluna 3: 4 + 8 + 12 + 16 = 40

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
