# Soma das Posições Ímpares

Mostra os valores de um vetor de 10 posições e soma os que estão nas **posições** ímpares (índices 1, 3, 5, 7 e 9).

## Conceitos praticados
- Diferença entre o índice e o valor de um vetor
- Paridade do índice com `%`

## Saída
```
 Os valores em cada casa de seu vetor sao
 Vetor[0] = 1
 Vetor[1] = 2
 ...
 Vetor[9] = 10
O valor da soma das posicoes impares do seu vetor = 30
```
(2 + 4 + 6 + 8 + 10 = 30)

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
