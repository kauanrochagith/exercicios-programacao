# Soma e Contagem com Do-While

Lê números inteiros até o usuário digitar **0**. Ao final, mostra quantos números foram digitados e a soma deles.

## Conceitos praticados
- Laço `do-while` (executa pelo menos uma vez)
- Valor sentinela (o `0` encerra a entrada)
- Acumulador (`soma`) e contador (`quantidade`)

## Exemplo
```
digite um numero
5
digite um numero
3
digite um numero
0

 Quantidade de numeros: 2
Soma:8
```

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
