# Percentual de Positivos, Negativos e Zeros

Lê 6 números inteiros, conta quantos são positivos, negativos e zeros e mostra o percentual de cada grupo.

## Conceitos praticados
- Classificação com `if / else if / else`
- Cálculo de porcentagem com conversão para `float`
- Impressão do símbolo `%` com `%%` no `printf`

## Exemplo
```
Digite 6 numeros inteiros:
5 -2 0 8 -1 3
Quantidade de positivos: 3
Quantidade de negativos: 2
Quantidade de zeros: 1
Percentual de positivos: 50.00%
Percentual de negativos: 33.33%
Percentual de zeros: 16.67%
```

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
