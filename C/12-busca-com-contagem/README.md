# Busca com Contagem de Ocorrências

Lê 10 números inteiros e um número para pesquisar. Mostra em quais posições ele aparece e quantas vezes no total.

## Conceitos praticados
- Busca linear em vetor
- Contador de ocorrências

## Exemplo
```
Digite 10 numeros inteiros:
4 7 4 1 9 4 2 8 3 5

Digite um numero para pesquisar: 4
O numero aparece na posicao: 0
O numero aparece na posicao: 2
O numero aparece na posicao: 5

O numero existe no vetor.
Ele aparece 3 vezes.
```

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
