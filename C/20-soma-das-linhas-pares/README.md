# Soma das Linhas Pares

Soma os elementos de cada linha de índice **par** (0 e 2) de uma matriz 3x3 e guarda os resultados em um vetor.

## Conceitos praticados
- Matriz inicializada na declaração
- Percorrer a matriz linha por linha
- Índice separado (`posicao`) para preencher outro vetor

## Saída
```
Vetor com as somas das linhas pares:
6 24
```
- Linha 0: 1 + 2 + 3 = 6
- Linha 2: 7 + 8 + 9 = 24

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
