# Intercalação de Vetores

Lê dois vetores **A** e **B** de 6 posições e monta um vetor **C**: as posições pares de C recebem o valor de A, e as ímpares recebem o de B.

## Conceitos praticados
- Vários vetores no mesmo programa
- Paridade do índice (`i % 2`) para decidir de onde copiar

## Exemplo
```
Digite os 6 elementos do vetor A:
1 2 3 4 5 6
Digite os 6 elementos do vetor B:
10 20 30 40 50 60
Vetor C:
1 20 3 40 5 60
```

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
