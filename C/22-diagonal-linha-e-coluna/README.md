# Diagonal, Linha e Coluna

*Exercício de prova.* Em uma matriz 3x3 fixa, calcula a soma da **diagonal principal**, da **segunda linha** e da **primeira coluna**.

```
6 6 3
8 8 1
2 3 1
```

## Conceitos praticados
- Acesso direto a posições da matriz (`valores[linha][coluna]`)
- Diferença entre fixar a linha e fixar a coluna

## Saída
```
Soma da diagonal principal: 15
Soma da segunda linha: 17
Soma da primeira coluna: 16
```

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
