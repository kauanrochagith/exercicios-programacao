# Soma dos Pares do Vetor

*Exercício de prova.* Mostra os valores de um vetor de 5 posições e soma os que são **pares**.

## Conceitos praticados
- Percorrer um vetor com `for`
- Testar a paridade do **valor** (compare com o exercício 18, que testa a **posição**)

## Saída
```
1
2
3
4
5
Soma dos numeros pares: 6
```

## Como compilar e executar
```
gcc main.c -o programa
./programa
```
